# Archivo del sistema anterior

Estos archivos conservan el trabajo anterior de Excel y Google Sheets. No se ejecutan ni forman parte de la aplicación actual. Los scripts conservan la última versión del sistema anterior y ya no tienen sus dependencias o rutas de ejecución antiguas.

La aplicación utiliza PostgreSQL en producción y SQLite en desarrollo local. Consulta el README de la raíz y `docs/GUIA-EDICION.md`.
