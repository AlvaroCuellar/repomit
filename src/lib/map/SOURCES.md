# Map data

Natural Earth (public domain), retrieved 2026-09-24 from the maintainer's repository:
- `italy.json`: Italy MultiPolygon from https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson
- `cities.json`: Italian populated places from https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_populated_places.geojson

Both outline and points use the same equirectangular projection (6–19° E, 35–48° N). Initial coordinates designate city centres at this dataset's resolution, not individual libraries. User corrections are stored independently and unknown cities are omitted until positioned.
